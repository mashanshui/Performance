## 构建声明与环境

| 项目 | 当前仓库配置 | 来源 |
| --- | --- | --- |
| Gradle Wrapper | 8.13 | [wrapper 配置](../../gradle/wrapper/gradle-wrapper.properties) |
| AGP / Kotlin | 8.13.2 / 2.2.10 | [版本目录](../../gradle/libs.versions.toml) |
| compileSdk | app 和 nativelib 均为 36 | 两模块 build.gradle.kts |
| minSdk | app 23；nativelib 21 | 两模块 defaultConfig |
| targetSdk | app 36 | [app 构建脚本](../../app/build.gradle.kts) |
| Java/Kotlin 字节码目标 | 11 | 两模块 compileOptions / jvmTarget |
| CMake | 3.22.1 | [库构建脚本](../../nativelib/build.gradle.kts) |
| ABI | 本库原生构建 arm64-v8a | 库 ndk.abiFilters |
| NDK | 未在模块脚本中显式锁定 ndkVersion | 以实际 AGP 解析和本地安装为准 |

Gradle 运行 JDK 与字节码目标分别配置。AGP 8.13 的最低 JDK 为 17，不能用模块 jvmTarget=11 推断运行 Gradle 只需 JDK 11。依据：[Android 官方 AGP 8.13 兼容表](https://developer.android.com/build/releases/agp-8-13-0-release-notes?hl=en)，核对于 2026-09-06。

准备可运行当前 Wrapper/AGP 的 JDK、Android SDK、NDK 和 CMake。SDK 本机路径保存在 local.properties，不提交到仓库。本轮没有检测当前终端的实际 JDK 或解析出的 NDK 版本。

## Rhea 本地依赖

[settings.gradle.kts](../../settings.gradle.kts) 为 `io.github.mashanshui` 配置 exclusiveContent，仅从 Maven Local 获取；库依赖 `io.github.mashanshui:rhea-inhouse:1.0.1`，并标记 changing、不缓存 changing 模块。

因此重新下载远端同名包无法替代本机依赖准备。缺少该坐标时应先在 Rhea 项目生成并发布正确制品；同版本重新发布也需要确认消费者真正解析到的新产物。仅看到坐标相同不能确认 ZIP 协议与 API 一致。

## 常用命令

以下 PowerShell 命令在项目根目录执行，属于操作指南，本轮没有执行：

~~~powershell
# 核对 Wrapper 和实际运行 JVM。
.\gradlew.bat --version

# 库 JVM 单测与示例应用构建。
.\gradlew.bat :nativelib:testDebugUnitTest
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug

# 按变更范围运行项目检查。
.\gradlew.bat check

# 仅在有明确设备验证任务和可用设备时运行。
.\gradlew.bat connectedAndroidTest
~~~

构建失败先复现具体任务，再处理运行 JDK、依赖解析或模块配置。缓存写入失败时检查实际 Gradle user home 的权限；不要把切换缓存目录误当成已经准备好 Rhea Maven Local。

## 测试地图

测试源码均位于 [nativelib/src/test](../../nativelib/src/test/java/com/example/nativelib)，以下为覆盖内容而非本轮通过记录。

| 测试类 | 覆盖内容 | 尚不能证明 |
| --- | --- | --- |
| PerformanceConfigTest / NativeServiceConfigTest | 默认值、自定义映射、参数限制、脱敏 | 真实组件启动与回滚 |
| ApplicationMetadataTest | 默认 buildId、versionCode 范围 | 所有 Android PackageManager 分支 |
| CrashEventFactoryTest | 堆栈/异常链限制、脱敏、启动事件 | 真正崩溃后进程行为 |
| FileCrashQueueTest / CrashUploaderTest | 文件状态、部分成功、重试、永久隔离 | 断电、多进程、当前服务端兼容 |
| FileJankUploadQueueTest / JankArtifactUploaderTest | 对账、状态恢复、原 ID 重试、本地删除重试 | Rhea 真采样与 ART ABI |
| FpsHelperV2Test | 累加器公式、有效帧过滤、刷新率归一化 | 真实 Window 回调 |
| FpsEventStoreTest / FpsUploaderTest | 同桶合并、快照恢复、duplicate、异常计数响应 | 完整生命周期、所有故障恢复 |
| NetworkClientTest | MockWebServer 请求/响应、ZIP 字节和日志 | 真实服务、设备网络策略 |
| FpsPageInstrumentedTest | 页面导航与控件显示 | FPS 数值、刷新率切换、后台停止的完整验收 |
| MemorySamplerTest / MemoryUploaderTest | PSS/VSS/Java 堆单位与缺失语义、批量确认、稳定 eventId、响应校验和重试 | 断电、长周期生命周期、真实永久拒绝和 503 故障注入 |
| MemorySamplingTimingTest | 真实进程内比较 `Debug.getPss()` 与 `Debug.MemoryInfo.totalPss`，以及 VSS、Java 堆读取耗时 | 事件构造落盘耗时、前后台周期、上传和长时间功耗 |

`app/src/test` 与通用 Example 测试主要是模板断言，不能纳入业务功能覆盖证明。详细设备测试入口见 [示例调试](10-示例应用与调试路径.md)。

2026-09-09 的内存设备验证使用了 Pixel 4 XL（Android API 33，arm64-v8a）。Debug 与 AndroidTest APK 构建成功后通过 `adb` 手动安装，执行 `MemorySamplingTimingTest` 得到 `OK (1 test)`；随后启动示例应用，确认断网事件写入 `noBackupFilesDir/performance-memory-reporter/events`，切到后台生成 `foreground=false` 样本，重启进程后原事件 ID 和载荷保持不变。服务端启动并执行 ClickHouse 内存表迁移后，设备真实请求落库；重放同一事件得到 `accepted=1`、`duplicate=1`，授权查询确认 summary/trend 返回 12 个去重样本。Gradle 设备部署器仍受 Windows 访问权限影响，未把手动安装结果表述为 `connectedAndroidTest` 通过。具体耗时分布和采集计划见 [线程调度与原生工具](07-线程调度与原生工具.md)。

## Maven Local 发布

库发布 release 变体及 sources JAR，默认坐标为 `com.example.nativelib:nativelib:1.0.0`。坐标覆盖和消费者配置以 [库发布入口](../../nativelib/README.md) 为准。

~~~powershell
# 只发布 nativelib 到当前用户的 Maven Local。
.\gradlew.bat :nativelib:publishToMavenLocal --no-daemon
~~~

默认产物目录是当前用户 Maven Local 下的 group/artifact/version 目录；实际路径可能受 Maven 配置影响。消费者需有 mavenLocal()，也需能够解析 POM/模块元数据声明的 Rhea 与其他依赖。

本次文档整理不执行发布。远程仓库和 Maven Central 不属于上述任务。
