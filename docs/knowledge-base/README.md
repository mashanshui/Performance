# Performance 项目知识库

本知识库解释当前代码的功能、调用链、设计取舍和验证边界。项目规则与维护入口位于根目录 [AGENTS.md](../../AGENTS.md)；SDK 接入参数以 [配置指南](../../nativelib/CONFIGURATION.md) 为详细参考。

## 阅读路径

- 首次了解项目：00 项目概览 → 01 模块架构 → 02 初始化 → 10 示例应用。
- 修改采集功能：对应的 03～07 专题 → 08 网络与队列 → 11 测试 → 12 待处理事项。
- 修改内存功能：13 内存指标链路；14 Activity 泄漏检测与 OOM 触发。
- 对接服务端：09 数据协议 → 08 确认与重试 → 对应功能专题。
- 排查问题：12 常见问题 → 对应调用链与测试入口。

## 文档分工与维护

- 本目录负责机制、调用链、设计取舍和验证范围；不为每个类单独生成一篇说明。
- [nativelib/README.md](../../nativelib/README.md) 是库的接入与发布入口。
- [CONFIGURATION.md](../../nativelib/CONFIGURATION.md) 统一维护配置字段、默认值与限制。
- [FPS_ALGORITHM.md](../../nativelib/FPS_ALGORITHM.md) 统一维护 FPS 公式、统计口径和典型日志。
- 00 集中记录能力状态和验证范围；12 集中记录差异和待处理问题，其他专题通过链接引用。
- 13 只描述 `memory_sample` 指标上传；Activity 泄漏检测不使用该事件、队列或上传器，统一见 14。
- 源码链接使用仓库相对路径，正文用类名与函数名定位，避免把易漂移的行号作为唯一依据。

## 事实来源与核对基线

首次整理日期：2026-09-06；Performance 源码基线：`0994c6b`。这是源码与文档核对基线，不代表该提交经过本次构建或真机验收。

客户端行为以本仓库源码为依据，服务端要求以 09 中引用的服务端契约为依据。两者不一致时同时记录，不能用文档抹平差异。测试源码只说明存在覆盖用例；测试通过需要执行记录，设备能力需要设备证据。外部 Rhea 二进制内部机制未经检查的部分明确保留为验证边界。

首次整理只进行源码/契约与文档检查；后续功能改造的实际执行记录统一见 [构建测试](11-构建测试与本地发布.md)，不以历史结果替代当前验证。
